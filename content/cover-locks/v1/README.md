# House lock v1 — drop the scan here

This directory is the versioned lock-file slot for article covers.

The lock is a **scan of the actual dry felt-tip on cream paper**, not a prompt
and not generated art. Design owns the first plates.

Drop the scan as `scan.jpg` (the filename `lock.json` cites). Until that file
is here and non-empty, studio publish fails closed: a plate cannot cite a lock
that has not been drawn.

Do not generate stock or AI art into this slot.
