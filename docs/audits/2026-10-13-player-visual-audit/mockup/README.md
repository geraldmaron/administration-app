# Economy interaction mockup

Design preview only; no application code changed. The editable fragment is presidential-economy.html; it renders inline in the design conversation. fixture-readings.json contains the existing gulf-oil-shock campaign's commodityBoard/commodityDetail output, extracted through the repository's register-player-core.mjs loader. No fabricated historical observations were added.

Interactions: commodity selection, finite history replay/pause/scrub, supplier and pressure previews, Escape/Back focus restoration, readable history/source disclosure, and host appearance/depth controls. Application navigation is presentation-only. Stock and supplier panels remain current snapshots during history replay. Historical converted prices are approximate because recorded indices are rounded; the latest quote retains the unrounded view-model figure ($102.65 for crude).

Verification: `python3 .../visualize/scripts/render.py <fragment> /private/tmp/presidential-economy-preview.html --force` rendered the preview. `node /private/tmp/check-economy.cjs` exited 0. verification.json records no page errors, no root horizontal overflow, and successful selection, scrub, finite replay completion, focus restoration and reduced-motion media checks. Browser viewports were 1440, 1024, 390 and 320; preview wrapper insets produced actual mock widths of 1408, 992, 358 and 288, respectively. Both themes were captured. Final full-page captures inspected: 1440 light and 320 dark; the earlier 1024 dark and 390 light composition was also visually inspected before the quote-precision/icon corrections. These checks cover the prototype only, not application integration or full accessibility certification.

The first browser launch was blocked by the filesystem sandbox; a disposable browser run with approved escalation succeeded. The first preview regeneration refused to overwrite an existing file, then succeeded with its documented --force flag. Two direct Node imports failed on extensionless module resolution; the existing repository loader resolved them. No dependency was added.

Known design limitations: logo and icon placeholders stand in for the existing game's registry; no map, live simulation adapter, historical supplier snapshots, typed pressure deep links or production route transitions are implemented here. The connection chain expresses existing modeled exposure, not a quantified forecast. Future production acceptance is specified in ../REDESIGN-PLAN.md.
